# CIVITAS · 시민의 시대

완전히 독립된 모바일 전략 게임 프로토타입입니다. 프리빌리지나 다른 프로젝트의 엔진·화면·저장 데이터를 사용하지 않습니다.

## 실행

Node.js 18 이상에서:

```sh
node server.js
```

그다음 `http://localhost:8080`을 엽니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

Playwright와 Chromium이 설치된 개발 환경에서는 `node scripts/check-playthrough.js`로 모바일 플레이와 세 가지 첫 권력 결말을 확인할 수 있습니다.

## 현재 플레이 조각

- 평민으로 시작해 여섯 번의 결정을 내립니다.
- 선택은 주민·상인·궁정·경비대의 지지, 신뢰, 조직력, 증거, 인맥을 바꿉니다.
- 도시 지도에서 행동할 구역을 고르면 그 지역에 기반을 둔 세력의 지지를 더 얻을 수 있습니다.
- 민심과 의회, 왕실 계승, 경찰·첩보 경로 중 쌓은 기반에 따라 첫 권력 자리가 달라집니다.
- 저장은 브라우저의 `localStorage`에 독립적으로 보관됩니다.
