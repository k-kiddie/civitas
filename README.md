# CIVITAS · 이름 없는 자들의 도시

모바일에서 평민 한 사람으로 시작해 도시의 제도와 역사를 바꾸고, 그 결과를 다음 세대에 물려주는 정치 전략 게임을 개발합니다. 크루세이더 킹즈의 인물과 계승, 문명의 장기 발전, 트로피코의 생활과 도시 운영을 같은 선택의 결과로 연결하는 것이 목표입니다.

## 플레이 방향

일하고 생계를 유지하며 현장을 조사합니다. 사람의 증언과 문서로 정보를 얻고, 공사·계약·선거에 개입합니다. 결정은 도시의 주거·일자리·물류와 개인의 기억에 남습니다. 직책을 얻으면 행사할 수 있는 권한과 책임이 달라집니다. 선거에서 져도 삶은 계속됩니다.

고정 28일 마감은 없습니다. 달력은 장마·선거·계약 만료를 알리고, 플레이어가 시간을 진행합니다. 평소 기간은 묶어서 넘기되 중요한 판단이 필요한 시점에서 멈춥니다. 실시간 접속 대기 없이 플레이합니다.

## 모바일 UI 목표

- 세로 화면의 도시 지도에서 장소와 계획을 선택합니다.
- 같은 지도 위에서 제방 후보와 영향받는 집, 공사비를 비교하고 별도로 확정합니다.
- 사람 수첩은 구체적인 기억과 약속, 알고 있는 사실을 보여줍니다.
- 행동 비용과 예상 결과를 선택 버튼 가까이에 표시합니다.
- 일정을 넘기기 전에 비용과 도착 시점을 표시합니다.

## 게임 시스템 목표

주민 다수는 구역별 집단으로 계산하고 주요 인물은 개별로 추적합니다. 인물은 자기 목표와 일정에 따라 움직이고, 비밀은 목격·증언·문서를 통해 퍼집니다. 계약에는 당사자·기간·대가·증인을 기록합니다. 공직에는 권한·임기·견제·해임 조건을 둡니다. 세대가 바뀌면 재산·건축물·법·계약은 남고 개인 관계는 새로 형성됩니다.

예를 들어 어촌까지 제방을 연장하면 주민이 살아남지만, 공사비를 댄 선주가 부두 사용료를 걷을 수 있습니다. 항구 교역과 주민의 표심이 바뀌고, 후계자는 그 계약 아래에서 다음 도시 계획을 결정합니다.

## 단계별 코딩 목표

1. **첫 장마와 선거** — 한 항구, 세 구역, 다섯 인물, 제방 한 안건을 연결합니다. 현장 조사·증언·계획 비교·자금 조달·침수와 이주·선거·다음 날 예산 집행까지 플레이합니다.
2. **인물과 정치극** — 인물별 목표와 일정, 정보 전달, 약속의 이행과 배신, 구역별 표심, 출처가 있는 증거와 후속 사건을 구현합니다.
3. **직업과 제도** — 동장·경찰·첩보원·의원의 고유 행동, 표결·수사·임명·해임을 구현합니다. 낙선과 해임 이후의 삶을 연결합니다.
4. **세대와 문명** — 후계자·상속·계약 만료·기술 변화·도시 확장·교역을 추가합니다. 대통령·왕·신정 지도자까지 서로 다른 권력 획득 과정을 만듭니다.

## 현재 구현 범위

1단계의 첫 플레이 흐름을 구현했습니다. 조사 이후 짧은 제방·긴 제방·보류를 비교하고, 긴 제방은 선주 계약 또는 주민 공동 출자를 택합니다. 12일의 장마는 침수 가구와 도시 인구를 바꿉니다. 20일 선거는 출마와 기권이 가능하고, 21일 이후 당선자는 정책을 집행하며 주민은 청원을 냅니다. 이후에도 날짜를 진행할 수 있습니다.

아직 지리 기반 침수 계산, 인물의 자율 행동, 구역별 투표, 실제 20년 계약 만료와 세대교체는 구현 전입니다. 현재 침수·지지는 명시된 규칙으로 계산하며, 제방 지도는 단순한 도식입니다. 장기 자유 플레이 콘텐츠는 다음 단계에서 확장합니다.

## 실행

Node.js 18 이상에서 `npm start`를 실행하고 `http://localhost:8080`에 접속합니다. AWS에서는 `PORT` 환경 변수로 포트를 지정합니다. 서버는 `0.0.0.0`에 바인딩합니다. `index.html`, `style.css`, `game.js`, `campaign.js`, `server.js`가 필요합니다.

`npm test`는 제방 선택, 자금 조달, 장마, 선거와 이후 진행 규칙을 확인합니다. 화면과 모바일 터치 사용성은 별도 브라우저 확인이 필요합니다.

저장은 브라우저 localStorage에 자동 보관됩니다. 새 캠페인은 `civitas-river-v3` 키를 사용하며 이전 프로토타입 저장은 삭제하지 않습니다. 계정 간 동기화와 저장 내보내기는 추후 구현합니다.

## 최근 개발 진행

2단계의 첫 변경을 반영했습니다. 소라에게 공개적으로 어촌 보호를 약속할 수 있고, 장마 때 실제 결정에 따라 약속 이행·위반이 기록됩니다. 공사 계약을 공개하면 지안과 민석이 증인으로 남습니다. 6일에는 소라가 공동 출자를 모집하고, 9일에는 조건에 따라 민석이 계약 사본을 요청합니다. 선거는 항구·어촌·언덕의 서로 다른 이해관계를 가중 합산하고 개표 화면에 구역별 결과를 표시합니다. 인물의 전체 자율 행동과 구역별 독립 경제는 후속 구현 대상입니다.

AWS 자동 시작 서비스 설치 방법은 [배포 안내](deploy/README.md)에 있습니다. 실제 서버 설치는 접속 정보 연결 후 진행합니다.
