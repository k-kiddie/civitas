# CIVITAS · 이름 없는 자들의 도시

모바일과 데스크톱에서 플레이하는 독립 정치 생존 게임. 안개 낀 항구 도시 벨라르에서 일용직 시민으로 시작하는 첫 장입니다.

## 실행

Node.js 18 이상에서 `node server.js` 실행 후 `http://localhost:8080`에 접속합니다. AWS에서는 `PORT` 환경 변수로 포트를 지정할 수 있으며 서버는 `0.0.0.0`에 바인딩합니다. `index.html`, `game.js`, `style.css`, `server.js`를 함께 배포해야 합니다.

## 첫 장의 규칙

- 28일 동안 하루 두 번 행동합니다. 노동으로 수입을 얻고, 휴식으로 기력을 회복하며, 구역별 활동으로 지지를 쌓습니다.
- 생활비는 하루 3크라운, 집세는 7일마다 12크라운입니다. 빚과 높은 감시는 기력·신뢰·수입에 불이익을 줍니다.
- 5개 사건의 15개 선택지는 인물 관계, 도시 식량·치안, 세력 지지를 바꿉니다. 배급 약속과 비밀 장부는 며칠 뒤 결과가 돌아옵니다.
- 지안·서윤·민석과 식사하며 관계를 쌓을 수 있습니다. 선거, 섭정, 수사처장 진출 조건은 권력 화면에서 확인합니다.
- 29일에 첫 직책이 결정되고, 취임 후 첫 정책을 선택합니다. 다음 장은 아직 구현하지 않았습니다.
- 저장은 브라우저 localStorage에 자동 보관합니다. 구형 시제품 저장과 분리됩니다. 서버 간 저장 동기화나 계정 기능은 없습니다.

## 확인

`node scripts/check-playthrough.js`는 실제 게임 코드를 실행해 세 진출 경로의 28일 플레이, 지연된 약속 위반, 저장 복원과 취임 정책을 확인합니다. 브라우저 화면 검사는 별도로 필요합니다.

폰트는 Google Fonts에서 가져오며, 연결할 수 없으면 시스템 폰트로 표시됩니다. 도시 풍경은 외부 이미지 없이 SVG로 렌더링합니다.
